# Задание 3: Создание векторного индекса

## Обзор

В этом задании мы создаем векторный индекс для базы знаний, используя эмбеддинги Sentence-Transformers и FAISS для векторного поиска.

## Технологии

- **Эмбеддинг-модель**: sentence-transformers/all-MiniLM-L6-v2
- **Векторная база**: FAISS (IndexFlatL2)
- **Язык**: Python 3.9+

## Установка зависимостей

```bash
pip3 install sentence-transformers faiss-cpu
```

## Создание векторного индекса

### Шаг 1: Запуск скрипта

```bash
python3 scripts/create_vector_index.py
```

### Шаг 2: Параметры

Скрипт использует следующие параметры (можно изменить в коде):

- `EMBEDDING_MODEL`: sentence-transformers/all-MiniLM-L6-v2
- `CHUNK_SIZE`: 500 токенов
- `CHUNK_OVERLAP`: 50 токенов
- `INDEX_PATH`: vector_index
- `KNOWLEDGE_BASE_PATH`: knowledge_base

### Шаг 3: Процесс создания

1. **Загрузка документов**: Скрипт загружает все `.txt` файлы из `knowledge_base/`
2. **Разбивка на чанки**: Тексты разбиваются на чанки с перекрытием
3. **Генерация эмбеддингов**: Создаются векторные представления для каждого чанка
4. **Создание индекса**: Векторы добавляются в FAISS индекс
5. **Сохранение**: Индекс и метаданные сохраняются в `vector_index/`

## Структура векторного индекса

```
vector_index/
├── faiss_index.bin      # FAISS индекс (бинарный файл)
├── chunks.pkl          # Чанки с метаданными (pickle)
└── index_info.json     # Информация об индексе
```

### index_info.json

```json
{
  "model_name": "sentence-transformers/all-MiniLM-L6-v2",
  "dimension": 384,
  "total_vectors": 67,
  "total_chunks": 67,
  "chunk_size": 500,
  "chunk_overlap": 50
}
```

## Использование индекса

### Пример кода для поиска

```python
import pickle
import faiss
from sentence_transformers import SentenceTransformer

# Загрузка индекса
index = faiss.read_index("vector_index/faiss_index.bin")

# Загрузка чанков
with open("vector_index/chunks.pkl", "rb") as f:
    chunks = pickle.load(f)

# Загрузка модели
model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

# Поиск
query = "Кто такой Гарри Поттер?"
query_embedding = model.encode([query])
distances, indices = index.search(query_embedding.astype('float32'), k=3)

# Вывод результатов
for i, (dist, idx) in enumerate(zip(distances[0], indices[0])):
    chunk = chunks[idx]
    print(f"Результат {i+1}:")
    print(f"  Расстояние: {dist:.4f}")
    print(f"  Источник: {chunk['source']}")
    print(f"  Текст: {chunk['text'][:200]}...")
```

## Параметры чанкования

### Размер чанка (CHUNK_SIZE)

- **Рекомендуемое значение**: 500 токенов
- **Минимальное**: 100 токенов
- **Максимальное**: 1000 токенов

**Влияние**:
- Большие чанки: больше контекста, но менее точный поиск
- Маленькие чанки: более точный поиск, но меньше контекста

### Перекрытие (CHUNK_OVERLAP)

- **Рекомендуемое значение**: 50 токенов (10% от размера чанка)
- **Минимальное**: 0 токенов
- **Максимальное**: 250 токенов (50% от размера чанка)

**Влияние**:
- Большое перекрытие: лучше захватывает контекст на границах чанков
- Маленькое перекрытие: быстрее обработка, но возможна потеря контекста

## Рекомендации по улучшению качества поиска

### 1. Улучшение чанкования

- Использовать семантическое чанкование (по смыслу, а не по размеру)
- Добавлять перекрытие на границах предложений
- Учитывать структуру документов (заголовки, параграфы)

### 2. Улучшение эмбеддингов

- Использовать более мощные модели (например, all-mpnet-base-v2)
- Дообучить модель на специфическом домене
- Использовать мультиязычные модели для поддержки русского языка

### 3. Улучшение поиска

- Использовать гибридный поиск (векторный + ключевыми словами)
- Добавить reranking (переупорядочивание результатов)
- Использовать фильтры по категориям, источникам и т.д.

### 4. Оптимизация производительности

- Использовать аппроксимативные индексы (IndexIVFFlat, IndexHNSW)
- Добавить кэширование для частых запросов
- Использовать батчевую обработку для множественных запросов

## Тестирование

### Тестовые запросы

Скрипт автоматически тестирует поиск с 4 запросами:

1. "Кто такой Гарри Поттер?"
2. "Какое зелье приносит удачу?"
3. "Какой факультет у Гарри Поттера?"
4. "Что такое патронус?"

### Оценка качества

- **Отличное**: Релевантные результаты в топ-1
- **Хорошее**: Релевантные результаты в топ-3
- **Удовлетворительное**: Релевантные результаты в топ-5
- **Плохое**: Нет релевантных результатов в топ-5

## Troubleshooting

### Ошибка: ModuleNotFoundError

**Проблема**: Не установлены зависимости

**Решение**:
```bash
pip3 install sentence-transformers faiss-cpu
```

### Ошибка: FileNotFoundError

**Проблема**: Не найдена база знаний

**Решение**: Убедитесь, что папка `knowledge_base/` существует и содержит `.txt` файлы

### Плохое качество поиска

**Проблема**: Результаты не релевантны запросам

**Решения**:
1. Увеличить размер чанка
2. Увеличить перекрытие
3. Использовать более мощную модель эмбеддингов
4. Улучшить качество исходных текстов
