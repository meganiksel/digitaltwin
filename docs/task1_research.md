# Задание 1: Исследование моделей и инфраструктуры

## 1. Сравнение LLM-моделей

### 1.1 Локальные модели Hugging Face

#### Mistral-7B-Instruct-v0.2

**Характеристики:**
- Параметры: 7.3B
- Контекст: 8K tokens
- Размер модели: ~15GB (FP16), ~4GB (4-bit quantization)
- Лицензия: Apache 2.0 (коммерческое использование)

**Качество ответов:**
- Высокое качество для задач QA и суммаризации
- Хорошее понимание инструкций
- Сильные результаты на бенчмарках (MMLU: ~60%)

**Скорость работы:**
- CPU: ~5-10 tokens/sec
- GPU (RTX 3060): ~50-80 tokens/sec
- 4-bit quantization: ~2-3x быстрее

**Стоимость владения:**
- Оборудование: $500-1000 (GPU) или $0 (CPU)
- Электроэнергия: ~$20-50/месяц
- API: $0 (локальное использование)

**Удобство развёртывания:**
- Простота установки через transformers
- Требует GPU для хорошей производительности
- Возможность quantization для запуска на CPU

#### Llama-3-8B-Instruct

**Характеристики:**
- Параметры: 8B
- Контекст: 8K tokens
- Размер модели: ~16GB (FP16), ~5GB (4-bit quantization)
- Лицензия: Llama 3 Community License (ограничения для >700M пользователей)

**Качество ответов:**
- Очень высокое качество, превосходит Mistral на многих бенчмарках
- Отличное понимание контекста
- MMLU: ~65%

**Скорость работы:**
- CPU: ~4-8 tokens/sec
- GPU (RTX 3060): ~40-70 tokens/sec
- Сlightly медленнее Mistral из-за большего размера

**Стоимость владения:**
- Оборудование: $500-1000 (GPU)
- Электроэнергия: ~$25-60/месяц
- API: $0 (локальное использование)

**Удобство развёртывания:**
- Простота установки через transformers
- Требует больше памяти, чем Mistral
- Лицензионные ограничения для крупных компаний

#### Qwen-7B-Instruct

**Характеристики:**
- Параметры: 7B
- Контекст: 8K tokens
- Размер модели: ~14GB (FP16), ~4GB (4-bit quantization)
- Лицензия: Tongyi Qianwen LICENSE (коммерческое использование)

**Качество ответов:**
- Хорошее качество, особенно для китайского языка
- Приемлемые результаты на английском
- MMLU: ~55%

**Скорость работы:**
- CPU: ~5-10 tokens/sec
- GPU (RTX 3060): ~50-80 tokens/sec
- Сравнима с Mistral

**Стоимость владения:**
- Оборудование: $500-1000 (GPU)
- Электроэнергия: ~$20-50/месяц
- API: $0 (локальное использование)

**Удобство развёртывания:**
- Простота установки
- Хорошая поддержка многоязычности

## 3. Сравнение векторных баз данных

### 3.1 FAISS

**Характеристики:**
- Разработчик: Meta (Facebook)
- Тип: In-memory библиотека
- Лицензия: MIT

**Скорость поиска:**
- IndexFlatL2: ~1K queries/sec (CPU)
- IndexIVFFlat: ~10K queries/sec (CPU)
- С GPU: ~100K queries/sec

**Скорость индексации:**
- ~10K docs/sec (CPU)
- Очень быстрая для больших объёмов

**Сложность внедрения:**
- Простая установка (pip install faiss-cpu)
- Требует программирования для интеграции
- Нет встроенного API

**Удобство в работе:**
- Минималистичный API
- Требует ручного управления метаданными
- Нет встроенного персистентного хранилища

**Стоимость владения:**
- Бесплатная библиотека
- Требует RAM для хранения индекса
- Для 100K чанков: ~2GB RAM

### 3.2 ChromaDB

**Характеристики:**
- Разработчик: Chroma
- Тип: Встроенная векторная БД
- Лицензия: Apache 2.0

**Скорость поиска:**
- ~5K queries/sec (CPU)
- Медленнее FAISS для больших объёмов

**Скорость индексации:**
- ~5K docs/sec (CPU)
- Медленнее FAISS

**Сложность внедрения:**
- Очень простая установка (pip install chromadb)
- Встроенный API и персистентность
- Простая интеграция с LangChain

**Удобство в работе:**
- Высокий уровень абстракции
- Встроенное управление метаданными
- Встроенное персистентное хранилище

**Стоимость владения:**
- Бесплатная
- Требует больше RAM (метаданные + индекс)
- Для 100K чанков: ~3-4GB RAM

## 6. Выбор для QuantumForge Software

### Рекомендуемый вариант: Вариант 2

**Обоснование:**

1. **Конфиденциальность данных:** Локальные модели гарантируют, что корпоративные данные не покидают периметр компании

2. **Стоимость:** Единовременные инвестиции в оборудование окупаются за 6-12 месяцев по сравнению с облачными решениями

3. **Производительность:** RTX 3060 обеспечивает достаточную скорость для корпоративного использования (~50-80 tokens/sec)

4. **Масштабируемость:** Конфигурация поддерживает рост базы знаний до ~100K чанков

5. **Качество:** Mistral-7B обеспечивает высокое качество ответов для корпоративных задач

6. **Простота:** FAISS и all-MiniLM-L6-v2 просты в внедрении и обслуживании

### Альтернативный вариант: Вариант 3 (облачный)

**Когда выбрать:**
- Ограниченный бюджет
- Необходимость быстрого запуска
- Отсутствие команды для обслуживания оборудования

**Риски:**
- Зависимость от внешних сервисов
- Меньшая конфиденциальность
- Постоянные операционные расходы
